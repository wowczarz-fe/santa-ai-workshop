How this works
  1. Read. Every text in the game is listed below, screen by screen, in the order a player meets it. Each one shows where it appears, the text in the game today and the text the editor proposes. Words that were added are marked in green and words that were removed are struck through in red.
  2. Decide. For each text, approve the proposal, keep the current text, or write your own version. You can add a comment to any text. Words in braces, such as {child}, are filled in by the game, so please leave them as they are.
  3. Export and send. When you have finished, or want to stop for now, choose Export my review and send the file back. Nothing in the game changes until your review has come back.

Your decisions are saved in this browser as you make them, so you can close the page and carry on later on the same computer.
