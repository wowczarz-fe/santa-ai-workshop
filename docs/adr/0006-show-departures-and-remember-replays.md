# Show departures and remember replays

## Context

Four sleigh departures give players time to see what their choices delivered and choose one improvement. Guidance must leave the elves and destinations usable. Feedback must show observed outcomes without revealing unchecked gifts.

## Considered options

- Keep upgrades beside the running line. That competes with staffing and checking decisions during play.
- Keep a comparison picker in the opening card. It distracts from starting a single game; query parameters remain sufficient for comparing versions.
- Replay the same letters by default. This makes repeat play predictable; a fixed seed in the address remains available for reproducible comparisons.

## Decision

Show the next cargo and its rules-provided target first in each paused break card, followed by the departure report and upgrade choices. Focus the next-cargo heading when the card opens so phone users see the announcement before scrolling. Keep a current-cargo badge beside the sleigh counter and carry cargo labels into the final run tiles. Keep the final Christmas account expanded, before the blunder collection, so all cost rows remain available without opening a toggle. Keep the rules' explanation of missed stars, mistakes and costs. Show only facts marked primary on case cards and make the full evidence available through information controls.

Protect every elf crew and movement destination when placing guidance, including alternative actions mentioned by the card. Keep native drag state separate from touch pointer cancellation.

Animate positive changes in the observed correct-gift count, and show supplied milestone, cleared-pile and checked-mistake events. Effects do not receive pointer input and remain static when motion is reduced.

Start replay immediately without guidance, using a fresh seed unless the address fixes one. Remember highest points and highest stars independently, plus uniquely identified blunders revealed by the rules. Show best-record comparisons only after a previous game exists, and celebrate improvements only for nonnegative scores. Saving the first result still establishes the next comparison. Storage failure keeps the game playable. Copy a result only when the player presses the copy button, with selectable text when clipboard access fails.

Show the rules-owned assurance verdict, group outcomes and real-world practice flags above the expanded money account. Underchecking counts actual costs of unchecked wrong deliveries and their late fixes; checked mistakes that were missed remain in shipped outcomes. Overchecking, prevented losses and the without-checks comparison are estimates. Explain that the comparison assumes all wrong toys made would ship, rather than simulating an alternative policy. Keep each paired practice flag separate. The practice terminology and article placeholder are provisional user wording. In the money account, compare people, AI, checking and fixing spending with the available budget. Show the cost of delivered wrong gifts separately; the wider total includes those consequences and is not budget spending.

## Consequences

The player can compare causes, costs and upgrades before the next run. Replays have variety while explicit seeds still reproduce a game. Local records belong to this browser. Movement, break cards, storage failure and touch information controls require browser checks alongside the rules checks.
